# Better Paseo assets

Published screenshots and demo videos for [Better Paseo](https://github.com/RoundRedDot/better-paseo), a [Paseo](https://paseo.sh) plugin. They back the plugin's listing on paseo.sh and are served through jsDelivr at a pinned commit, so the files keep their image and video content types.

`promo-v14/` holds the release published as [`promo-v14`](https://github.com/RoundRedDot/better-paseo/releases/tag/promo-v14) on the plugin repository: two 1080p demo videos (timeline and Tasks board), the cover, the README screenshots and the gallery images.

Only finished, published media live here. The plugin's code stays in RoundRedDot/better-paseo.
